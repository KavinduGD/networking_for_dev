# Tailscale setup with multiple users

- Create a Tailscale account and set up your tailnet.
- Add all users to your tailnet. Each user will need to install Tailscale on their devices and log in with their Tailscale account.
- Now each user can access the devices in the tailnet using their Tailscale IP addresses or device names.

---

- one instance cannot be in two tailnets at the same time. If you want to share access to a device with another tailnet, you can use Tailscale's sharing feature or set up a relay server.
